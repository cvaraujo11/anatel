# Exemplo de Cronograma de Pausas (Sessão de 2 Horas)

Este é um exemplo simples usando uma variação da Técnica Pomodoro.

- **00:00 - 00:25:** Estudo Focado
- **00:25 - 00:30:** Pausa Curta (5 min) - Alongue-se, beba água.
- **00:30 - 00:55:** Estudo Focado
- **00:55 - 01:00:** Pausa Curta (5 min) - Olhe pela janela, respire fundo.
- **01:00 - 01:25:** Estudo Focado
- **01:25 - 01:30:** Pausa Curta (5 min) - Caminhe um pouco.
- **01:30 - 01:55:** Estudo Focado
- **01:55 - 02:00:** Pausa Curta (5 min) - Prepare-se para finalizar ou para uma pausa maior.

**Após 2 horas:** Faça uma pausa mais longa (15-30 minutos) se for continuar estudando, ou encerre a sessão.

**Dica:** Ajuste os tempos conforme sua necessidade e nível de concentração. O importante é fazer pausas regulares!
