**Questão 4 (Equações Logarítmicas)**

Se log₃(x) = 2, qual é o valor de *x*?

a) 2
b) 3
c) 5
d) 6
e) 9

## Gabarito

1.  **c)** (31 é divisível apenas por 1 e por ele mesmo)
2.  **c)** (Juros = C * i * t = 2000 * 0,02 * 6 = 240. Montante = C + J = 2000 + 240 = 2240)
3.  **c)** (3x = 14 + 7 => 3x = 21 => x = 7)
4.  **e)** (Pela definição de logaritmo, 3² = x => x = 9)
